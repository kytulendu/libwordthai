# Rama Spell Check File Format

Use both Kaset (เกษตร) and TIS-620 character encoding.

The program have control code samilair to [Rajavithi Word PC](fmt_Rajavithi_Word_PC.md).

Rama Spell Check version 2.1 have extended the control code supported and add more functionlity like picture printing support and store option at the end of the file.
