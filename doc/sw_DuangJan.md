# DuangJan (ดวงจันทร์) Word Processor

DuangJan (ดวงจันทร์) is a Thai/English word processor for IBM PC compatible from MegaChomp Company.

The software support CGA and Hercules graphic card.

Later version branded as DuangJan International Bilingual Word Processor, which have version that support Armenian, Bengali, Burmes, European, Greek, Gujarati, Hindi, Khmer, Lao, Punjabi, Russian, Sinhalese, Tamil, Thai and Vietnamese.
